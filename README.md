## 🚀 Featured Projects

### 💊 MediNear — Smart Medicine & Pharmacy Finder

A MERN stack application designed to help users find medicines and nearby pharmacies.

**Key Features**

- Medicine availability search
- Smart pharmacy ranking
- Open/closed pharmacy status
- Distance-based pharmacy discovery
- Emergency / 24-hour pharmacy mode
- Customer and pharmacy-owner workflows

**Tech:** React • Node.js • Express.js • MongoDB

---

### 🌐 NetQuiz — Networking Learning Platform

A MERN stack learning application for revising computer networking concepts.

**Key Features**

- 12 networking topics
- 1,200 multiple-choice questions
- User authentication
- Randomized quizzes
- Answer explanations
- Quiz results and history

**Tech:** React • Node.js • Express.js • MongoDB

---

### 👥 ProjectMate — Student Project Team Builder

A mobile application that helps students find suitable project teammates and manage project teams.

**Key Features**

- Project creation
- Team management
- Mobile-first experience
